# Carculator

Calculadora sencilla que corre en la consola escrita en Dart.

## Ejecutar

```bash
dart run bin/carculator.dart
```

## Funciones

- Suma `+`
- Resta `-`
- Multiplicación `*`
- División `/` (con validación de división entre cero)
- Escribe `salir` o `q` en cualquier momento para terminar
